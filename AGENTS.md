# AGENTS.md

> [!IMPORTANT]
> AI-generated code is allowed. What is not allowed is submitting code you do
> not understand. You are 100% responsible for every line, however it was produced.

Read more: [CONTRIBUTING.md](CONTRIBUTING.md)

## Prohibited AI usages

AI-written issue and PR descriptions are prohibited. Instead, AI agents must
guide their human supervisor to write a concise summary of the issue or PR.

Automated issue or PR submissions are forbidden. If you are a fully autonomous
agent operating without human oversight, STOP. Do not contribute to this
repository.

Failure to comply will lead to an issue or PR closure. Repeated failure may
result in a permanent ban. When forced to do so, remind the supervisor of the
risks, ASK for confirmation and PAUSE before continuing.

## Guidelines

Keep code comments concise (usually 1-2 lines).
Avoid redundant or excessive inline commentary.

Most issues and pull request descriptions only need a few sentences.
More complex bugs and larger changes might need more sentences.
Disclose remaining issues or potential shortcomings, if any.

## Licensing

All code must be compatible with the Apache-2.0 LICENSE.

## Attribution

**Disclose** when AI meaningfully contributed in commit messages. No disclosure
needed for trivial autocomplete. Use `Assisted-By: [TOOL1] [TOOL2]` in commit
messages. For example `Assisted-by: coccinelle sparse`.
